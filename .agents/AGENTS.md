# SortGems Pixel Art & Puzzle Design Rules

このファイルは、SortGemsのステージピクセルアート（ドット絵）およびパズルの品質を保証するための制作・修正ルールを定義しています。今後エージェントがステージを追加・修正する際は、必ずこのルールを厳守してください。

## 1. キャンバスサイズと余白の配置ルール
- **左右対称オブジェクトの設計**: ハート、星、砂時計などの左右対称の被写体は、中央に1マスの背骨（中心線）を持たせるため、必ず**奇数サイズ（13x13, 15x15, 17x17など）**のグリッドでアートを設計・定義してください。
- **偏った余白の禁止**: 偶数サイズ（12x12など）のアートを奇数サイズのグリッドに配置する際、単純な左上詰め（オフセット0）にすると、右端と下端だけに不自然な余白ができ、画面上でオブジェクトが偏って見えます。必ず上下左右の余白が均等（差が1マス以内）になるようにセンタリングを行ってください。
- **境界余白の確保**: アートがグリッドの端に直接接していると窮屈に見えるため、原則として**上下左右に最低1マス以上の空きマス（余白）**を確保してください。

## 2. パズル品質と色数のルール
- **最低マス数の保証**: パズルとしての面白さと戦略性を保つため、使用する各色は**最低でも3マス（推奨4マス以上）**で構成してください。
- **ノイズカラー（極小色）の禁止**: 1〜2マスしかない色は、1回動かすだけでソートが完了してしまい、ゲームプレイを単調にする原因になります。グラデーション表現やアンチエイリアスのために1〜2マスだけの別色を散りばめることは避けてください。
- **色の占有率の制限**: 1つの色が全体の充填マスの55%以上を占めないようにしてください（単色で埋め尽くされた大領域はパズルとしての手応えを損ないます）。

## 3. ドットの連結と孤立マスの排除ルール
- **孤立ドットの禁止**: 8方向（上下左右斜め）に同じ色のマスが隣接していない「孤立した1マス（単発ドット）」は配置しないでください。パズルにおいて視覚的なノイズとなり、操作に混乱を招きます。すべてのドットは、同色の他のドットと必ず連結している必要があります。

## 4. 適切な充填率（Density）の維持
- **充填率の範囲**: グリッド全体の面積に対するジェム配置マスの割合（充填率）は、**35%〜80%**の範囲内に収めてください。
- **スカスカ感の解消**: 充填率が30%未満のステージ（キャンドルや三日月など）は、グリッドサイズ自体を縮小するか、被写体のドットを太く描いて密度を高めてください。
